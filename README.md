# ECHOID landing page

A single-viewport, responsive React landing page based on the supplied ECHOID design brief. The page uses the specified CloudFront hero video and poster, Google Fonts, desktop navigation, mobile menu, email-entry UI, and legal footer. It does not include an authentication or signup backend; form submission is intentionally prevented, as requested.

## Run locally

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```
