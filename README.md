# Aura — AI-native email client landing page

Responsive cinematic landing page for Aura, built with React 18, TypeScript, Vite, Tailwind CSS, Motion, and Lucide.

## Development

```sh
pnpm install --frozen-lockfile
pnpm dev
```

## Production build

```sh
pnpm install --frozen-lockfile
pnpm build
```

The static production output is written to `dist/`. The website is released through its Manus deployment. GitHub Pages is not configured for this repository.
